# Repository Instructions

- If you commit anything in this repository, first make sure `FAST-Python-Wrapper` is up to date by going to that repository, making the corresponding edits, committing them, and then returning here to continue.

- After committing and pushing changes on the `triet` branch, update the `external/FAST` submodule in both `ASTRA` and `GenGNNs4GPSA` to the new commit, then commit and push each parent repository's submodule pointer. Preserve unrelated changes in both parent repositories.
